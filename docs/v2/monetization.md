## 2. 핵심 설계 질문

- [ ] **PG 선택**: 토스페이먼츠 vs 포트원(v2) vs 아임포트 — 수수료/결제수단/정산 비교
- [ ] **원장 구조**: 멤버십 구독 + 포인트(리워드) + 도네이션을 **하나의 원장**으로 통합 vs 분리
- [ ] **환불/해지 정책**: 월/연 구독 비례환불, 미사용 포인트 환급 기준
- [ ] **세금계산서/영수증**: 사업자 발행 요건 (간이/일반 과세)
- [ ] **해외결제**: Apple Pay / Google Pay / 글로벌 카드 지원 여부
- [ ] **도네이션 실시간 표시**: 채팅창 오버레이 vs 별도 UI — 모더레이션 필요성
- [ ] **광고 SSP**: Google AdSense/AdManager vs 국내 애드팝콘 등 — 수익성/UX 비교
- [ ] **리워드 소진 채널**: 포인트 → 멤버십 결제 상쇄 / 상품 교환 / 현금화 여부 (법 검토)

## 3. 선행 의존성

- **인증**: 실명 확인 필요 시 본인인증 (PG 요구 조건)
- **법무/세무**: 전자상거래법, 통신판매업 신고, 세무 신고 플로우
- **커뮤니티**: 멤버십 배지/등급이 커뮤니티에 표시되므로 커뮤니티(P0) 선행
- **실시간 인프라**: 도네이션은 채팅(P0) WebSocket 기반
