## 2. 핵심 설계 질문

- [ ] **엔티티 모델**: Post / Comment / Reaction / Report / Block 관계 정의 (그래프 vs 플랫)
- [ ] **모더레이션 정책**: 신고 임계값, 자동 숨김, 관리자 검토 SLA
- [ ] **아티스트별 채널 구조**: 아티스트 단위 vs 전역 타임라인 vs 하이브리드
- [ ] **AI 필터 연동**: Django sidecar `#206` comment AI filter 재사용 여부 (Fail-Pending 전략)
- [ ] **알림 설계**: 멘션/답글/좋아요/팔로우 — 푸시 없이 인앱으로만?
- [ ] **투표 중복 방지**: 1인 1표 기준 (계정? 디바이스? IP?)
- [ ] **투표 결과 공개 시점**: 진행 중 실시간 vs 종료 후 공개
